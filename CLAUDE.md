# Ilona Clinic — Project Instructions

## Required Reading at Session Start

**Before any code change**, read these two files:

1. `learning.md` — project reference: stack, all DB tables, migrations, key patterns, hooks, components
2. `memory.md` — session log: what was built, what's pending, what migrations still need to run in Supabase

## Session End

When finishing a significant session, update `memory.md` — add a new entry at the top with today's date and a summary of what was done.
